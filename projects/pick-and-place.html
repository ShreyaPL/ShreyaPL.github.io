Pick and Place using 7-DOF Franka Panda Arm

Project Overview

This project demonstrates the design and implementation of a pick-and-place system using the Franka Emika Panda 7-degree-of-freedom robotic arm. Leveraging forward and inverse kinematics, vision-based block detection, and precision control, the robot performs automated stacking of static and dynamic blocks in both simulation and hardware testing.

Problem Statement

Efficient object manipulation and placement in unstructured environments pose significant challenges due to the complexity of robotic arm kinematics, dynamic object detection, and collision avoidance.

Solution & Technical Approach

  • Implemented both forward and inverse kinematics for 7-DOF Franka Panda.
  • Developed camera-based block detection with pose estimation and orientation correction.
  • Designed control logic for safe grasping, precise pick-and-place, and stacking of blocks.
  • Used ROS and C++ for robot control and integration.

Implementation Highlights

  • Applied Denavit-Hartenberg parameters for kinematic modeling.
  • Average multiple sensor readings to improve pose accuracy.
  • Stacked static blocks methodically with collision avoidance using seed configurations for inverse kinematics.
  • Dynamic blocks handled via sweeping detection and repositioning strategy.
  • Repeated testing performed in both simulation and physical hardware setups.

Results & Impact

  • Reduced average pick-and-place transition time for static blocks to approximately 11 seconds per block.
  • Achieved 60% reduction in sorting errors through vision and kinematic tuning.
  • Demonstrated reliable stacking on hardware with minor alignment deviations (~1 cm offset).

Challenges & Learning

Initial gripper control functions were unreliable, requiring alternative command implementations. Camera APRIL tag detection inconsistencies led to misaligned grasping early on. Adjustments in sweeping strategy and block orientation calculations greatly improved reliability and robustness.
